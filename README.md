# excel_dio
# 📊 Análise de Perfis de Investimento em Fundos Imobiliários (FIIs) | DIO

Projeto desenvolvido durante o bootcamp de **Excel da DIO (Digital Innovation One)**, com foco na estruturação profissional de dados, organização visual e uso de fórmulas para análise de **Fundos Imobiliários (FIIs)** com base nos perfis de investimento.

---

## 📌 Objetivos do Projeto
- **Organização Profissional:** Estruturação visual limpa e intuitiva para facilita a leitura de dados financeiros.
- **Análise por Perfil de Investidor:** Mapeamento de categorias de FIIs (Papel, Tijolo, Híbridos, FOFs, etc.) alinhadas aos perfis **Conservador**, **Moderado** e **Agressivo**.
- **Automação de Consultas:** Utilização da função `PROCV` para busca dinâmica de informações nas tabelas.
- **Agilidade e Produtividade:** Aplicação do atalho `Alt + =` (AutoSoma) e outras funções de cálculo rápido.

---

## 🛠️ Tecnologias e Ferramentas
- **Microsoft Excel**
- **Fórmulas:** `PROCV`, `SE`, `CONCATENAR` / `&`, `SOMA`
- **Atalhos:** `Alt + =` (AutoSoma)
- **Design de Planilhas:** Formatação condicional e segmentação de colunas

---

## 📂 Como Usar
1. Baixe o arquivo `.xlsx` disponível neste repositório.
2. Abra no Microsoft Excel ou Google Planilhas.
3. Navegue entre as abas e consulte a distribuição dos ativos por perfil.
